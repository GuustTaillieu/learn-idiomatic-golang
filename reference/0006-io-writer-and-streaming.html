Reference: io.Writer, Streaming & Channel Pub-Sub Hub

The fundamental building blocks of real-time I/O, streaming protocols, and channel broadcast architectures in Go.

The Core I/O Abstraction:

Go's entire I/O ecosystem revolves around one single interface:

type Writer interface {
    Write(p []byte) (n int, err error)
}

Because http.ResponseWriter, os.Stdout, bytes.Buffer, and net.Conn all implement io.Writer, you can stream data to any destination without changing your core logic.

1. Server-Sent Events (SSE) with http.Flusher

SSE is pure HTTP. It keeps the TCP connection open and streams text frames formatted as data: <payload>\n\n.

func handleEvents(w http.ResponseWriter, r *http.Request) {
    // 1. Mandatory SSE headers
    w.Header().Set("Content-Type", "text/event-stream")
    w.Header().Set("Cache-Control", "no-cache")
    w.Header().Set("Connection", "keep-alive")

    // 2. Type-assert the http.Flusher interface
    flusher, ok := w.(http.Flusher)
    if !ok {
        http.Error(w, "Streaming unsupported", http.StatusInternalServerError)
        return
    }

    // 3. Stream frames as they happen
    for {
        select {
        case <-r.Context().Done(): // Client closed the tab/connection
            return
        case event := <-clientChan:
            // Write to io.Writer
            fmt.Fprintf(w, "data: %s\n\n", event.JSON())
            // Flush immediately to the wire
            flusher.Flush()
        }
    }
}

2. The Channel Broker / Pub-Sub Hub Pattern

How to safely broadcast events to 1 to 10,000 concurrent HTTP clients without race conditions or memory leaks:

type Hub[T any] struct {
    mu          sync.RWMutex
    subscribers map[chan T]struct{}
}

func NewHub[T any]() *Hub[T] {
    return &Hub[T]{
        subscribers: make(map[chan T]struct{}),
    }
}

func (h *Hub[T]) Subscribe() chan T {
    h.mu.Lock()
    defer h.mu.Unlock()
    ch := make(chan T, 16) // Buffered to handle small bursts
    h.subscribers[ch] = struct{}{}
    return ch
}

func (h *Hub[T]) Unsubscribe(ch chan T) {
    h.mu.Lock()
    defer h.mu.Unlock()
    delete(h.subscribers, ch)
    close(ch)
}

func (h *Hub[T]) Broadcast(event T) {
    h.mu.RLock()
    defer h.mu.RUnlock()
    for ch := range h.subscribers {
        select {
        case ch <- event: // Sent successfully
        default:          // Slow subscriber buffer is full; drop to protect server!
        }
    }
}

3. Non-Blocking Sends: Protecting the Server

In high-concurrency Go, never block on an untrusted subscriber channel:

// ❌ Dangerous: One slow client with high network latency halts your entire backend worker pool!
ch <- event 

// ✅ Senior Pattern: Non-blocking send drops or logs if subscriber cannot keep up
select {
case ch <- event:
default:
    // Subscriber buffer full; skip or disconnect
}
