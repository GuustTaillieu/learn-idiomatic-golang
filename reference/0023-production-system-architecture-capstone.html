Reference: Production Go System Architecture Capstone

The complete blueprint of the production-grade concurrent order processing system built across 50 lessons.

The Hallmarks of a Senior Go Engineer:
  • Standard Library First: Rely on Go primitives (net/http, sync, context, log/slog, //go:embed) before importing third-party frameworks.
  • Explicit Over Magic: Explicit dependency injection, functional options, and clear package boundaries (Ben Johnson layout).
  • Fault-Tolerant Concurrency: Goroutines guarded by channels, worker pools, errgroup, and idempotent graceful shutdown semantics.
  • Defensive Distributed Design: Transactional Outbox pattern with Claim-Check state machines, saga compensation rollbacks, and W3C distributed trace propagation.

1. Complete Architecture Map

Layer Package Responsibility
Domain Core internal/domain Pure business entities (Order, Item, Stock), strongly-typed IDs, sentinel errors, interfaces.
Storage & Migrations internal/sqlite Embedded SQL migrations (//go:embed), atomic SQLite transactions, and idempotent seeding.
Saga Processors internal/processor Composite sagas (OrderPlacing, Paying) with automatic rollback closures on failure.
Asynchronous Core internal/queue, internal/domain/outbox Bounded worker queues, transactional outbox polling with claim-check state machine.
Event Streaming internal/event Thread-safe generic Pub/Sub hub with non-blocking sends for real-time SSE streaming.
Protocols & API internal/http, proto/ Connect-RPC service, modern Go 1.22 http.ServeMux, token-bucket rate limiting, and request correlation IDs.
Observability internal/telemetry OpenTelemetry distributed tracing, W3C traceparent propagation, health probes, and live pprof profiling.
Packaging Dockerfile Multi-stage static compilation (CGO_ENABLED=0) running on Google Distroless (<25MB).
