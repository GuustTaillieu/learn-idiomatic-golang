Reference: Standalone Type-Safe Client Architecture

How external services, CLI tools, and web frontends consume your backend with 100% compile-time type safety and zero internal dependencies.

The Public API Boundary Rule:
"An external consumer must NEVER import internal packages. The public contract (proto definitions and generated client stubs) lives in a public root directory (or dedicated SDK repository), while all database, queue, and handler logic remains strictly encapsulated in internal/."

1. Package Boundary Enforcement in Go

├── cmd/
│   ├── server/       # Service binary (imports internal/ + proto/)
│   └── client/       # External standalone client (imports ONLY proto/)
├── internal/         # STRICTLY PRIVATE (Go compiler blocks external imports)
│   ├── domain/
│   ├── sqlite/
│   ├── processor/
│   └── http/
└── proto/            # PUBLIC CONTRACT (Available to external modules)
    └── order/v1/
        ├── order.proto
        ├── order.pb.go
        └── orderv1connect/order.connect.go

2. Wire Protocols: JSON vs Binary Protobuf vs gRPC

Protocol Client Use Case Wire Format Performance
Connect (Binary Protobuf) Go Microservices / CLI Binary (application/proto) ⚡ Highest throughput, 70% smaller payloads, 0 JSON parsing overhead.
Connect (JSON) Web Browsers (fetch) / curl JSON (application/json) 🔍 Human-readable, native browser compatibility with zero build steps.
Traditional gRPC Legacy Services / Kubernetes Ingress HTTP/2 Trailers + Binary 🔗 Full compatibility with existing gRPC load balancers and Envoy proxies.

3. Building the Optimized Client Stub

// Client configured with high-performance HTTP/2 transport and binary protocol
httpClient := &http.Client{
    Timeout: 10 * time.Second,
    Transport: &http.Transport{
        MaxIdleConns:        100,
        MaxIdleConnsPerHost: 20,
        IdleConnTimeout:     90 * time.Second,
        ForceAttemptHTTP2:   true,
    },
}

// Client imports ONLY public orderv1connect
client := orderv1connect.NewOrderServiceClient(
    httpClient,
    "http://localhost:8080",
    connect.WithProtoJSON(), // or binary by default
)

4. Web Frontend (TypeScript / React) Client

In an independent frontend repo (e.g. Next.js, Vite, React), you generate TypeScript types using @bufbuild/protobuf:

import { createClient } from "@connectrpc/connect";
import { createConnectTransport } from "@connectrpc/connect-web";
import { OrderService } from "./gen/order_connect";

const transport = createConnectTransport({
  baseUrl: "http://localhost:8080",
});

const client = createClient(OrderService, transport);

// 100% type-safe call with autocompletion!
const res = await client.createOrder({
  itemId: "00000000-0000-0000-0000-000000000001",
  amount: 2,
});
console.log(res.orderId);
