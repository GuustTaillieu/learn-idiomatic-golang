Reference: Production Profiling with pprof & Goroutine Leak Hunting

The authoritative guide to inspecting CPU, memory, and goroutines in live production Go services.

The Superpower of Go Runtime Diagnostics:

Go has industrial-grade profiling built directly into the runtime. By adding one standard library blank import, your server exposes live endpoints for CPU, heap, goroutine stacks, and mutex contention without third-party agents.

1. Enabling pprof in net/http

import _ "net/http/pprof"

If you use http.DefaultServeMux, routes are automatically registered under /debug/pprof/.

If using a custom http.NewServeMux() (Go 1.22+), register them manually or attach a separate internal admin port:

// In custom mux:
mux.HandleFunc("GET /debug/pprof/", pprof.Index)
mux.HandleFunc("GET /debug/pprof/cmdline", pprof.Cmdline)
mux.HandleFunc("GET /debug/pprof/profile", pprof.Profile)
mux.HandleFunc("GET /debug/pprof/symbol", pprof.Symbol)
mux.HandleFunc("GET /debug/pprof/trace", pprof.Trace)

2. Essential Terminal Diagnostics Commands

Command Diagnosis Purpose
go tool pprof http://localhost:8080/debug/pprof/profile?seconds=30 Captures 30 seconds of CPU activity to find CPU hotspots.
go tool pprof http://localhost:8080/debug/pprof/heap Analyzes memory heap allocations to find memory leaks.
go tool pprof http://localhost:8080/debug/pprof/goroutine Inspects all active goroutine stack traces to detect leaked goroutines.
curl -s http://localhost:8080/debug/pprof/goroutine?debug=1 Prints a human-readable list of all running goroutines and where they are waiting.

3. Top Commands Inside Interactive pprof Shell

  • top10: Shows the top 10 functions consuming CPU or memory.
  • top -cum: Shows cumulative consumption (including children called).
  • list <FunctionName>: Displays line-by-line source code annotated with exact CPU time or bytes allocated.
  • web: Generates an SVG graph / flame graph in your default browser (requires Graphviz).

4. Detecting Goroutine Leaks in Unit Tests

func TestNoGoroutineLeaks(t *testing.T) {
    initial := runtime.NumGoroutine()

    // Run queue, server, or async operation...
    runSystem()

    // Wait or assert goroutine count returned to baseline
    if remaining := runtime.NumGoroutine(); remaining > initial {
        t.Errorf("Leaked %d goroutines!", remaining - initial)
    }
}
