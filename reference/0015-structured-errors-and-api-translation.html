Reference: Structured Error Classification & Boundary Translation

How senior Go engineers translate domain, storage, and context errors across HTTP and RPC boundaries without leaking abstractions or exposing internal state.

The Core Boundary Principle:
"Internal error details (SQL syntax, connection drops, disk failures) must never leak into client responses. Domain sentinel errors must map deterministically to standard HTTP status codes. All unclassified errors are internal (500) and must be logged with context."

1. Sentinel Errors vs Custom Error Types

Pattern When To Use Detection Method
Sentinel Error
var ErrNotFound = errors.New(...)		 Static failure states with no extra dynamic attributes. errors.Is(err, domain.ErrNotFound)
Custom Error Type
type ValidationError struct { Field, Message string }		 Dynamic errors with payload details needed by caller (e.g. form fields). var vErr *ValidationError
if errors.As(err, &vErr) { ... }

2. Preserving The Error Chain (%w vs %v)

// CORRECT: Preserves causal chain for errors.Is / errors.As
if errors.Is(err, sql.ErrNoRows) {
    return nil, fmt.Errorf("order query: %w", domain.ErrOrderNotFound)
}

// INCORRECT: Destroys causal chain (%v turns error into plain string)
return nil, fmt.Errorf("order query failed: %v", domain.ErrOrderNotFound)

3. The Leaky Abstraction Trap

Consider this common junior anti-pattern:

// ANTI-PATTERN:
order, err := store.Get(r.Context(), id)
if err != nil {
    // If the database crashed or pool timed out, the client receives 404!
    // The client falsely assumes the order does not exist and tries to recreate it.
    http.Error(w, "not found", http.StatusNotFound)
    return
}

4. Centralized HTTP Error Translator

func RespondError(w http.ResponseWriter, r *http.Request, err error) {
    switch {
    case errors.Is(err, domain.ErrOrderNotFound), errors.Is(err, domain.ErrItemNotFound):
        http.Error(w, err.Error(), http.StatusNotFound)

    case errors.Is(err, domain.ErrInsufficientStock):
        http.Error(w, err.Error(), http.StatusConflict)

    case errors.Is(err, context.DeadlineExceeded):
        http.Error(w, "request timed out", http.StatusGatewayTimeout)

    case errors.Is(err, context.Canceled):
        // Client closed connection early
        w.WriteHeader(499)

    default:
        // Internal failure: log contextually with request ID, hide SQL/system details from caller
        slog.ErrorContext(r.Context(), "unhandled internal server error", "error", err)
        http.Error(w, "internal server error", http.StatusInternalServerError)
    }
}
