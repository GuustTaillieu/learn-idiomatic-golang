Reference: High-Concurrency Load Testing & Stress Simulation

How senior Go engineers validate distributed systems under extreme concurrency, backpressure, and resource contention.

The Load Testing Mental Model:
"A distributed system is only as reliable as its behavior under maximum saturation. If it doesn't degrade gracefully under load, it will collapse catastrophically in production."

1. Anatomy of a Concurrent Go Load Generator

// Worker Pool Generator Pattern
type LoadTester struct {
    client      *http.Client
    targetURL   string
    concurrency int
    totalReqs   int
}

func (lt *LoadTester) Run(ctx context.Context) Result {
    jobs := make(chan int, lt.concurrency*2)
    var wg sync.WaitGroup
    var metrics Metrics

    for i := 0; i < lt.concurrency; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for id := range jobs {
                start := time.Now()
                statusCode, err := lt.sendRequest(ctx, id)
                metrics.Record(time.Since(start), statusCode, err)
            }
        }()
    }

    // Feed work to workers
    for i := 0; i < lt.totalReqs; i++ {
        jobs <- i
    }
    close(jobs)
    wg.Wait()
    return metrics.Summary()
}

2. HTTP Client Connection Reuse & Connection Leaks

Default http.DefaultClient has a shared transport that allows at most 2 idle connections per host (DefaultMaxIdleConnsPerHost = 2). Under heavy load, requests will constantly open and close TCP sockets, causing port exhaustion (TIME_WAIT sockets).

// Senior High-Throughput HTTP Transport
client := &http.Client{
    Timeout: 5 * time.Second,
    Transport: &http.Transport{
        MaxIdleConns:        1000,
        MaxIdleConnsPerHost: 200,
        IdleConnTimeout:     90 * time.Second,
    },
}

3. Key Metrics to Measure

  • Throughput (RPS): Requests successfully processed per second.
  • Latency Percentiles (p50, p95, p99): Tail latency under saturation.
  • Error Rates: 429 Too Many Requests (Rate Limiter working!), 500 Internal Server Error (Database contention / locks), 504 Gateway Timeout.
