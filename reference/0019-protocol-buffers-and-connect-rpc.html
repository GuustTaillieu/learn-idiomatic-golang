Reference: Protocol Buffers & Connect-RPC

The modern, browser-friendly RPC architecture for type-safe Go microservices and web frontends.

The Contract-First Principle:
"Code written to serialize and deserialize JSON manually rots. Define your data structures and API procedures once in Protocol Buffers, and let code generators produce type-safe clients and servers."

1. Traditional gRPC vs Connect-RPC

Feature Traditional gRPC (google.golang.org/grpc) Connect-RPC (connectrpc.com/connect)
Browser Support Requires Envoy proxy (browsers can't send HTTP/2 trailers). Works natively in browsers over standard HTTP/1.1 & HTTP/2!
Routing Requires dedicated gRPC server running on separate port or h2c multiplexer. Mounts directly onto standard Go net/http and http.ServeMux!
Protocols Supported gRPC only. gRPC, gRPC-Web, and Connect (JSON & binary Protobuf) on same port!
Tooling Requires heavyweight gRPC plugins. Standard protoc or Buf CLI.

2. Anatomy of a .proto File

syntax = "proto3";

package order.v1;

option go_package = "github.com/GuustTaillieu/idiomatic-go/proto/order/v1;orderv1";

service OrderService {
  rpc CreateOrder(CreateOrderRequest) returns (CreateOrderResponse);
  rpc GetOrder(GetOrderRequest) returns (GetOrderResponse);
}

message CreateOrderRequest {
  string item_id = 1;
  int32 amount = 2;
}

message CreateOrderResponse {
  string order_id = 1;
  string status = 2;
}

message GetOrderRequest {
  string order_id = 1;
}

message GetOrderResponse {
  string order_id = 1;
  string item_id = 2;
  int32 amount = 3;
  string status = 4;
}

3. Compiling Protobuf in Go

protoc --go_out=. --go_opt=paths=source_relative \
       --connect-go_out=. --connect-go_opt=paths=source_relative \
       proto/order/v1/order.proto

4. Implementing and Mounting a Connect Handler

type OrderServer struct {
    store domain.OrderStorer
}

func (s *OrderServer) CreateOrder(
    ctx context.Context,
    req *connect.Request[orderv1.CreateOrderRequest],
) (*connect.Response[orderv1.CreateOrderResponse], error) {
    // Access typed payload via req.Msg
    order := domain.NewOrder(domain.ItemID(uuid.MustParse(req.Msg.ItemId)), int(req.Msg.Amount))
    if err := s.store.Save(ctx, order); err != nil {
        return nil, connect.NewError(connect.CodeInternal, err)
    }
    return connect.NewResponse(&orderv1.CreateOrderResponse{
        OrderId: order.ID.String(),
        Status:  string(order.Status),
    }), nil
}

// Mounting onto standard http.ServeMux:
path, handler := orderv1connect.NewOrderServiceHandler(&OrderServer{store: store})
mux.Handle(path, handler)
