Reference: Idiomatic Go Naming Conventions

The mental models and rules of thumb for naming variables, receivers, packages, and interfaces in Go.

1. The Golden Rule of Go Naming

"The greater the distance between a name's declaration and its uses, the longer the name should be."
— Rob Pike (Co-designer of Go)
  • Tiny Scope (1–5 lines): Short, single-letter names convey high density and reduce visual noise (e.g. i, err, o, r, w).
  • Medium Scope (10–30 lines): Descriptive single words (e.g. order, stock, payload).
  • Broad/Package Scope (Exported identifiers): Fully descriptive, precise names (e.g. OutboxDispatcher, ErrInsufficientStock).

2. Method Receiver Names

In Go, method receivers are not called this or self.

  • Use 1 or 2 letters representing the type:
    • func (s *OrderSqliteStore) Save(...) → s for Store.
    • func (q *Queue) Submit(...) → q for Queue.
    • func (h *Handler) Routes(...) → h for Handler.
    • func (p *PlaceOrderProcessor) Process(...) → p for Processor.
  • Rule of Consistency: Never use s in one method of a struct and store in another. Pick one and use it across the entire file.

3. Avoiding "Stutter" in Package & Type Names

Callers always use a symbol with its package prefix: package.Symbol.

Non-Idiomatic (Stuttering) Idiomatic Go Caller Usage
store.OrderStore store.Order or store.SQLite store.SQLite (reads as "store's SQLite implementation")
httpapi.HTTPHandler httpapi.Handler httpapi.Handler
domain.DomainOrder domain.Order domain.Order

4. Standard Canonical Abbreviations

  • ctx: context.Context (always the first parameter).
  • err: error (always the last return value).
  • w: http.ResponseWriter or io.Writer.
  • r: *http.Request or io.Reader.
  • mu: sync.Mutex or sync.RWMutex.
  • wg: sync.WaitGroup.
  • req / res: HTTP or RPC request and response structs.
  • tx: *sql.Tx (database transaction).

5. When is a Name "Too Short"?

A name is too short when:

  1. Multiple concepts collide: If a function takes an OrderStore and a Stock, naming both s causes confusion. Use store and stock instead!
  2. Distance is large: If a variable is declared on line 12 and referenced on line 55, a 1-letter name forces the reader to scroll up. Give it a descriptive name like pendingOrders.
