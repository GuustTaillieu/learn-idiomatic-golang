Reference: 12-Factor Configuration & Fail-Fast Startup

The senior pattern for robust, environment-driven configuration with zero external dependencies.

The Fail-Fast Principle:
"A service must validate its entire configuration at startup before opening database connections or binding network ports. If a required value is missing or invalid, crash immediately with an actionable error message."

1. The Strongly-Typed Config Struct

type Config struct {
    Port         string
    DatabaseURL  string
    WorkerCount  int
    RateLimit    float64
    RateBurst    int
    ShutdownTime time.Duration
}

2. Loading Hierarchy (Flags → Env → Defaults)

  1. Default Values: Built into the code for instant local development (go run cmd/server/main.go works out of the box).
  2. Environment Variables: Read via os.LookupEnv (standard for Docker / Kubernetes 12-factor apps).
  3. CLI Flags: Read via flag package to allow command-line overrides during debugging or ad-hoc runs.

3. Helper for Type-Safe Environment Parsing

func getEnv(key, fallback string) string {
    if val, ok := os.LookupEnv(key); ok && val != "" {
        return val
    }
    return fallback
}

func getEnvInt(key string, fallback int) int {
    if val, ok := os.LookupEnv(key); ok {
        if i, err := strconv.Atoi(val); err == nil {
            return i
        }
    }
    return fallback
}

4. Strict Fail-Fast Validation

func (c *Config) Validate() error {
    if c.WorkerCount <= 0 {
        return errors.New("WORKER_COUNT must be greater than 0")
    }
    if c.DatabaseURL == "" {
        return errors.New("DATABASE_URL cannot be empty")
    }
    if c.RateLimit <= 0 {
        return errors.New("RATE_LIMIT must be greater than 0")
    }
    return nil
}
