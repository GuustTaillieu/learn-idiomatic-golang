1. Deep Dive: Reviewing internal/domain/item.go

A. Binary vs Hex UUIDs in sql.Scanner

In your Scan implementation:

case []byte:
    u, err := uuid.Parse(string(v)) // ⚠️ Gotcha!

If a database driver returns a 16-byte raw binary UUID (such as an SQLite blob or PostgreSQL binary column), string(v) converts raw bytes into a garbled 16-character string instead of a 36-character hexadecimal string ("6ba7b810-..."). uuid.Parse will fail with a syntax error!

        return nil

B. Unmarshaling without Reflection

In UnmarshalJSON, calling json.Unmarshal(data, uuidPointer) spins up Go's reflection engine and unmarshals recursively. Since you already have the underlying uuid.UUID, you can delegate directly:

func (id *ItemID) UnmarshalJSON(data []byte) error {
    return (*uuid.UUID)(id).UnmarshalJSON(data)
}

C. When are Functional Options Idiomatic for Entities?

Functional Options shine when:

  1. Configuring complex services with many options (e.g. server.New(opts...), queue.New(opts...)).
  2. Protecting invariants on unexported fields (e.g. ensuring name != "").

For pure data entities with exported fields (ID, Name, CreatedAt), standard struct literals (Item{...}) are zero-allocation. However, having WithID and WithCreatedAt is very practical when hydrating records from databases or in test factories!

2. Turning RunWithCache into a Generic Singleflight[T]

In internal/lib/db_cache.go, you attempted a generic wrapper around singleflight. That's a great instinct! To make it work, the group must be a struct that lives across requests:

package lib

import (
    "context"
    "fmt"
    "golang.org/x/sync/singleflight"
)

type Singleflight[T any] struct {
    group singleflight.Group
}

func (s *Singleflight[T]) Do(key string, fn func() (T, error)) (T, error) {
    var zero T
    result, err, _ := s.group.Do(key, func() (any, error) {
        return fn()
    })
    if err != nil {
        return zero, err
    }
    val, ok := result.(T)
    if !ok {
        return zero, fmt.Errorf("unexpected type: %T", result)
    }
    return val, nil
}

Now any store can embed Singleflight[*domain.Stock] as a field, giving 100% type-safe deduplication without any type casting at the call site!

3. Senior Concurrency Tooling: Benchmarking with testing.B

How do senior engineers prove their singleflight or caching layer actually makes their software faster? With Go's built-in benchmark harness!

func BenchmarkCachedInventory_Get(b *testing.B) {
    store := NewMockStore()
