1. The Problem: How Do You Log HTTP Status Codes in Go?

In Node.js or Python frameworks, the response object has res.statusCode. But in Go's standard library net/http, http.ResponseWriter is an interface with only three methods:

type ResponseWriter interface {
    Header() Header
    Write([]byte) (int, error)
    WriteHeader(statusCode int)
}

There is no StatusCode() getter! Once your handler calls w.WriteHeader(http.StatusCreated), that number is pushed into the HTTP socket and gone forever.

2. The Go Solution: Decorating http.ResponseWriter

To inspect status codes and measure response payload size in an access-logging middleware, you wrap w in a custom struct that embeds http.ResponseWriter:

type statusRecorder struct {
    http.ResponseWriter
    status int
    bytes  int
}

func (r *statusRecorder) WriteHeader(code int) {
    r.status = code
    r.ResponseWriter.WriteHeader(code)
}

func (r *statusRecorder) Write(b []byte) (int, error) {
    n, err := r.ResponseWriter.Write(b)
    r.bytes += n
    return n, err
}

3. The Streaming Trap: Don't Break http.Flusher!

Here is where intermediate Go developers break production:

Remember how your live SSE dashboard calls:

flusher, ok := w.(http.Flusher)
if !ok {
    http.Error(w, "Streaming unsupported", 500)
    return
}

If you wrap w with statusRecorder, w.(http.Flusher) will return false! Why? Because statusRecorder does not implement Flush(), so your live SSE dashboard will crash with Streaming unsupported!

The Senior Fix: Implement Flush() on your recorder and delegate it to the underlying ResponseWriter:

func (r *statusRecorder) Flush() {
    if flusher, ok := r.ResponseWriter.(http.Flusher); ok {
        flusher.Flush()
    }
}

4. Building LoggingMiddleware

func LoggingMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()
        rec := &statusRecorder{ResponseWriter: w, status: http.StatusOK}

        next.ServeHTTP(rec, r)

        lib.Logger(r.Context()).Info("HTTP request",
            "method", r.Method,
            "path", r.URL.Path,
            "status", rec.status,
            "bytes", rec.bytes,
            "duration", time.Since(start),
        )
    })
}
