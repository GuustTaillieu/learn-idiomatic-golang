Lesson 0034: Single-Binary Applications with //go:embed & Real-Time Web Dashboards

Target: Transform your backend into a complete, self-contained single binary application that serves a live, reactive frontend dashboard using Go's embed.FS.

Review of Your Event Hub & SSE Implementation:
  • 🎉 Textbook Idiomatic Design: You defined domain.Hub[T] as an interface in the domain, and implemented it in internal/event/hub.go. Pure decoupling!
  • ✨ Non-Blocking Safety: Your select { case ch <- event: default: } prevents slow clients from freezing backend workers.
  • 🛡️ Zero Resource Leaks: In handleGetEvents, defer h.orderHub.Unsubscribe(subscriber) cleanly unregisters channels as soon as the client disconnects!
  • 💡 Receiver Nuance on Task.MarshalJSON: In internal/queue/task.go, MarshalJSON has a pointer receiver (t *Task[T]). For safer automatic serialization with json.Marshal, value receivers (t Task[T]) are preferred on types broadcasted as values.

1. The Go Superpower: //go:embed

In most programming languages (Node.js, Python, Ruby), deploying a web application with a frontend requires:

  • Installing dependencies (node_modules).
  • Configuring Nginx or reverse proxies for static assets.
  • Managing complex multi-stage Docker build containers and volume mounts.

In Go, the standard library includes //go:embed (since Go 1.16). You can compile HTML, CSS, JavaScript, images, and SQL migrations directly into your compiled machine binary!

You can compile your app, copy the single 15MB binary to an empty Linux server, and execute it. It will serve the API, process background queues, and host the web dashboard with zero external runtime files!

2. How Embedded File Serving Works

package web

import (
    "embed"
    "io/fs"
    "net/http"
)

//go:embed static/*
var staticFS embed.FS

func FileServer() http.Handler {
    // Strip "static" prefix so static/index.html is served at root "/"
    sub, err := fs.Sub(staticFS, "static")
    if err != nil {
        panic(err)
    }
    return http.FileServer(http.FS(sub))
}

3. Mounting Static Files in http.ServeMux

In internal/http/handler.go, mount the embedded file server on the root path:

mux := http.NewServeMux()

// API Routes
mux.HandleFunc("POST /orders", h.handleCreateorder)
mux.HandleFunc("GET /orders/{id}", h.handleGetorder)
mux.HandleFunc("GET /events", h.handleGetEvents)
mux.HandleFunc("GET /healthz", h.handleHealth)
mux.HandleFunc("GET /readyz", h.handleReady)

// Embedded Web Dashboard
mux.Handle("GET /", web.FileServer())

4. The Live Order Dashboard in Action

We created a modern, dark-mode real-time dashboard in web/static/index.html:

  • Connects directly to your GET /events SSE stream using the browser's native EventSource API.
  • Features a "Submit Order" form that posts to POST /orders.
  • Renders animated cards for each task as your background workers progress from PENDING → PROCESSING → COMPLETED in real time!
