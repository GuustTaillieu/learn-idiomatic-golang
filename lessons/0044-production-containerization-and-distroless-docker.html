1. Why Most Dockerfiles in Go Are Bad

Many developers package Go apps like Node or Python apps:

# THE BAD JUNIOR DOCKERFILE:
FROM golang:1.24
COPY . .
RUN go build -o server ./cmd/server
CMD ["./server"]
# RESULT: 1.2 GB image containing git, gcc, bash, package managers, and 500+ CVE vulnerabilities!

In Go, the compiler produces a standalone machine code binary. The container doesn't need Go, bash, apt, or curl to run it!

2. The Distroless Advantage

Google Distroless (gcr.io/distroless/static-debian12:nonroot) contains only what a static Go binary needs: CA root certificates (for HTTPS outbound requests) and basic timezone data. It has:

  • No package manager (apt, apk) → Attackers cannot install tools.
  • No shell (/bin/sh, /bin/bash) → Prevents remote command injection shells.
  • Runs as nonroot:nonroot (UID 65532) → Zero root privileges inside the container.
  • Total image size: ~20 MB!

3. Why Pure Go SQLite (modernc.org/sqlite) Shines Here

If you used mattn/go-sqlite3, you would need gcc and a C runtime (libc), making static compilation tricky. Because you chose modernc.org/sqlite, it compiles with CGO_ENABLED=0 into a 100% statically linked binary that runs seamlessly on scratch or distroless!

Your Hands-On Challenge

  1. Create Dockerfile in the workspace root:
    • Stage 1 (Builder): Use golang:1.24-alpine, copy go.mod/go.sum, download modules, copy source, and build with CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o /app/server ./cmd/server.
    • Stage 2 (Runtime): Use gcr.io/distroless/static-debian12:nonroot. Copy the binary to /app/server, expose port 8080, and set entrypoint.
  2. Create .dockerignore:
    • Exclude local orders.db, .git, test caches, and temporary files.
  3. Build your container image: 
    docker build -t gopher-order:latest .
  4. Inspect the image size: 
    docker images gopher-order:latest
    (Verify it is tiny—under 35MB!)
  5. Run your containerized app: 
    docker run --rm -p 8080:8080 -e PORT=8080 gopher-order:latest
  6. In another terminal, test it with your stress tool or browser: 
    go run cmd/stress/main.go -c 10 -n 50
