1. Why uuid.FromBytes Doesn't Exist in Go 1.27

In older third-party packages like github.com/google/uuid, there was a helper function uuid.FromBytes(b).

In Go 1.27's standard library package uuid, UUID is defined as:

type UUID [16]byte

Because UUID is a 16-byte array, Go has built-in slice-to-array conversion syntax (since Go 1.20). You don't need a function; the language does it natively:

case []byte:
    if len(v) == 16 {
        *id = ItemID(v) // or ItemID([16]byte(v))
        return nil
    }
    // If it's a 36-byte hex string (e.g. SQLite text column as bytes):
    u, err := uuid.Parse(string(v))
    ...

2. The "JSON Quote Trap": Why UnmarshalText Failed

In internal/domain/item.go, you wrote:

func (id *ItemID) UnmarshalJSON(data []byte) error {
    return (*uuid.UUID)(id).UnmarshalText(data) // ⚠️ Fails with "invalid uuid"
}

What Happened Behind the Scenes:

When JSON unmarshals a string value like {"item_id": "c58a3430-8057-..."}, UnmarshalJSON receives the raw JSON token, which includes the enclosing double quotes:

data = []byte("\"c58a3430-8057-...\"") // Length is 38 bytes, starts and ends with "

uuid.UUID.UnmarshalText expects exactly 36 raw hexadecimal characters without quotes. When it sees " as the first byte, it immediately aborts with invalid uuid!

This is why TestHandler_GetOrderRoute and TestHandler_CreateOrderRoute failed: the HTTP handler could not decode incoming or outgoing JSON requests containing ItemID.

3. The Two Idiomatic Go Solutions

Solution A: Delegate to json.Unmarshal (Like in order.go)

Let encoding/json unquote the string first:

func (id *ItemID) UnmarshalJSON(data []byte) error {
    return json.Unmarshal(data, (*uuid.UUID)(id))
}

Solution B: The Industry Standard for Scalar Types (TextMarshaler)

In idiomatic Go, custom scalar types (like UUIDs, IP addresses, Money, and timestamps) implement encoding.TextMarshaler and encoding.TextUnmarshaler:

// MarshalText implements encoding.TextMarshaler
func (id ItemID) MarshalText() ([]byte, error) {
    return uuid.UUID(id).MarshalText()
}

// UnmarshalText implements encoding.TextUnmarshaler
func (id *ItemID) UnmarshalText(data []byte) error {
    return (*uuid.UUID)(id).UnmarshalText(data)
}

Why is this superior?

  • encoding/json natively supports TextMarshaler and TextUnmarshaler! It automatically adds quotes when marshaling and strips quotes before passing bytes to UnmarshalText.
  • You can delete MarshalJSON and UnmarshalJSON entirely!
  • It also works seamlessly with XML, YAML, URL query parameters, and CLI flags.
