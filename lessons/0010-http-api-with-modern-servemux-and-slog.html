1. Connecting to the Real World: The HTTP Layer

We have an asynchronous worker engine (internal/queue) and a persistent state repository (internal/store). Now, we need the front door of our application: HTTP Endpoints.

In our e-commerce checkout flow:

  • POST /tasks: The checkout page sends an order. We save it as StatusPending, submit it to our queue, and immediately respond with HTTP 202 Accepted: 
    {
  "id": "7b8f9e12-...",
  "status": "PENDING"
}
  • GET /tasks/{id}: The customer's order tracking page polls for progress. We read from our store and return the current status (PENDING, RUNNING, COMPLETED, or FAILED). If it doesn't exist, we return HTTP 404 Not Found.

2. Modern Go Standard Library Routing (Go 1.22+)

Prior to Go 1.22, developers had to use third-party routers like Chi or Gorilla Mux to match methods and URL parameters. In modern Go, the standard library http.ServeMux supports this natively:

mux := http.NewServeMux()

// Match method and path
mux.HandleFunc("POST /tasks", handler.handleCreateTask)

// Extract path parameter: {id}
mux.HandleFunc("GET /tasks/{id}", handler.handleGetTask)

// Inside the handler:
func (h *Handler) handleGetTask(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id") // Built-in parameter extraction!
}

3. Senior Go HTTP Idioms

  • Decode JSON from the stream: 
    var req struct { Payload string `json:"payload"` }
if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
    http.Error(w, "invalid request body", http.StatusBadRequest)
    return
}
  • Return JSON with correct headers: 
    w.Header().Set("Content-Type", "application/json")
w.WriteHeader(http.StatusAccepted)
json.NewEncoder(w).Encode(task)
  • Structured Logging (log/slog): 
    slog.InfoContext(r.Context(), "task submitted", "task_id", task.ID)
