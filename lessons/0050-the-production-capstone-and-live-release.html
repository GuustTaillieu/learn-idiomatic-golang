1. The Final Wire: Connecting the Dashboard to Connect-RPC

In web/static/index.html, notice how the browser dispatches orders today:

const res = await fetch('/orders', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({item_id: itemId, amount: amount})
});

Because Connect-RPC accepts standard JSON over HTTP POST, you can switch the URL to your generated RPC service:

const res = await fetch('/order.v1.OrderService/CreateOrder', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({item_id: itemId, amount: amount})
});
const data = await res.json();
console.log("Order created via Connect-RPC:", data.orderId);

The exact same backend service handles browser JSON and binary microservice protobuf!

2. The End-to-End Capstone Verification

To verify the entire distributed system end-to-end:

  1. Start the Server: 
    go run cmd/server/main.go
  2. Open the Dashboard at http://localhost:8080. Verify the SSE connection indicator glows green.
  3. Place an Order from the UI: Click "Dispatch to Outbox". Observe the real-time state transition from PENDING → PROCESSING → COMPLETED!
  4. Run the High-Concurrency Load Tester in another terminal: 
    go run cmd/stress/main.go -c 20 -n 100
    Watch your Token Bucket rate limiter protect the server, and watch the dashboard stream live updates without dropping connections!
  5. Verify System Diagnostics: Visit http://localhost:8080/debug/pprof/ to inspect active goroutines and memory heap.
  6. Verify Unit Tests & Race Detector: 
    go test -v -race ./...
