Lesson 0049: Asynchronous Trace Propagation & W3C TraceContext

Target: Answer your question about task context! Propagate trace IDs across the Outbox database boundary into worker goroutines using standard W3C TraceContext.

Answering Your Question:
"If I had to do something with the task ctx then I don't know how (if it matters)?"

It matters enormously in distributed systems! Here is why:

  • When an order arrives via RPC or HTTP, it has a request context: r.Context().
  • That request creates a span with a unique TraceID.
  • The order is written to SQLite and the HTTP response returns 201 Created. The HTTP request is now finished and its context is canceled!
  • Moments later, the Outbox Dispatcher polls SQLite and feeds the order to your background worker pool.

If the worker pool tried to use the original HTTP request context, it would immediately crash with context canceled! But if it uses a fresh context.Background(), the trace is broken and the worker's execution looks like a completely separate, anonymous task in Datadog/Jaeger.

1. The Solution: W3C TraceParent Serialization

In industry standards (OpenTelemetry, AWS X-Ray, Google Cloud Trace), trace identifiers are represented as a compact string called a TraceParent:

00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01

When the order is placed, we inject this string into the order. When the background worker picks up the order, it extracts the trace metadata into its server context! Now the worker's spans become children of the original RPC request span.

2. Building the Trace Injector and Extractor

// internal/telemetry/propagation.go
package telemetry

import (
    "context"
    "go.opentelemetry.io/otel/propagation"
)

var propagator = propagation.TraceContext{}

// InjectTraceParent writes the current span's W3C traceparent string
func InjectTraceParent(ctx context.Context) string {
    carrier := propagation.MapCarrier{}
    propagator.Inject(ctx, carrier)
    return carrier["traceparent"]
}

// ExtractTraceContext extracts the traceparent into a base context
func ExtractTraceContext(ctx context.Context, traceParent string) context.Context {
    if traceParent == "" {
        return ctx
    }
    carrier := propagation.MapCarrier{"traceparent": traceParent}
    return propagator.Extract(ctx, carrier)
}

3. Attaching It to Domain Orders

Add a field to internal/domain/order.go:

type Order struct {
    ID          OrderID
    ItemID      ItemID
    Amount      int
    Status      OrderStatus
    TraceParent string // W3C distributed trace string!
    ...
}

Your Hands-On Challenge

  1. Create internal/telemetry/propagation.go:
    • Implement InjectTraceParent(ctx context.Context) string using propagation.TraceContext{}.
    • Implement ExtractTraceContext(ctx context.Context, traceParent string) context.Context.
  2. In internal/domain/order.go:
    • Add TraceParent string `json:"trace_parent,omitempty"` to the Order struct.
  3. In internal/http/order_rpc.go:
    • In CreateOrder, capture the trace: 
      order.TraceParent = telemetry.InjectTraceParent(ctx)
  4. In internal/processor/order_placing.go:
    • Resume the trace inside Process: 
      ctx = telemetry.ExtractTraceContext(ctx, order.TraceParent)
ctx, span := telemetry.StartSpan(ctx, "processor.OrderPlacing")
defer span.End()
